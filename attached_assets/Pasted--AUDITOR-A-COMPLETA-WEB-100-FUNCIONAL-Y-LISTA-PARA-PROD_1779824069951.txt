## 🎨 AUDITORÍA VISUAL & DISEÑO

### A. TIPOGRAFÍA
- [ ] **Revisar todas las fuentes**
  - Verificar que las familias de fuentes sean consistentes
  - Comprobar que los tamaños sean legibles (min 14px en mobile)
  - Revisar contraste de colores (mínimo WCAG AA: 4.5:1 para texto)
  - Verificar que títulos tengan jerarquía clara (H1 > H2 > H3 > etc)

- [ ] **Espaciado de líneas**
  - Line-height mínimo 1.5 en textos largos
  - Párrafos con separación clara
  - Listas con indentación visible

- [ ] **Estilos de texto**
  - ¿Hay texto en MAYÚSCULAS innecesarias? → Cambiar a normal
  - ¿Hay palabras juntas sin espacios? → Buscar y corregir
  - ¿Existen textos truncados (...)? → Revisar y expandir

### B. COLORES & CONTRASTE
- [ ] Revisar paleta de colores en toda la web
- [ ] Usar https://webaim.org/resources/contrastchecker/
- [ ] Verificar que botones sean distinguibles
- [ ] Revisar que enlaces sean identificables (subrayados o color distinto)

### C. ESPACIADO & ALINEACIÓN
- [ ] Márgenes consistentes entre secciones
- [ ] Padding uniforme en contenedores
- [ ] Alineación de elementos (izquierda, centro, derecha)
- [ ] Sin elementos desalineados o "flotando"

### D. ELEMENTOS VISUALES
- [ ] Iconos: todos visibles, correctamente escalados
- [ ] Badges (NUEVO, SIN SELLOS): colores claros y diferenciados
- [ ] Bordes y sombras: consistentes y sutiles
- [ ] Animaciones: fluidas, no lentas, no molestas

### B. BÚSQUEDA DE ERRORES COMUNES

```
BUSCAR EN TODA LA WEB (Ctrl+F):

❌ "  " (doble espacio) → cambiar por un espacio
❌ "  " (espacios extras) → limpiar
❌ Palabras EN MAYÚS innecesarias → cambiar a normal
❌ "..." (puntos suspensivos incompletos)
❌ Caracteres raros o especiales malformateados
❌ URLs rotas (href="#" o links inválidos)
❌ "lorem ipsum" u otro texto placeholder
❌ "[TODO]" o comentarios de código
❌ Números sin formato (19999 → 19.999 o $19.999)
❌ Teléfonos sin formato
❌ Emails sin @ o mal escritos
```

## 🖼️ CÓMO SUBIR IMÁGENES

### MÉTODO 1: Subida desde Galería del Dispositivo

**Dónde aplica**: Fotos de productos, posts, recetas  
**Tipos de archivo**: JPG, PNG, WebP (máximo 5MB)

#### Paso a paso:

```
1. Haz clic en el botón: [📁 Seleccionar imagen]

2. Se abre una ventana de tu computadora con tus archivos

3. Busca la carpeta donde tienes la imagen:
   Típicamente: Descargas, Imágenes, Documentos

4. Haz clic en la imagen que quieres

5. Haz clic en [Abrir] o [Seleccionar]

6. Verás una VISTA PREVIA:
   ┌──────────────────┐
   │ [Imagen aquí]    │
   │                  │
   │ ✏️ Editar        │
   │ ❌ Eliminar      │
   │ ✅ Guardar       │
   └──────────────────┘

```


## ❓ PREGUNTAS FRECUENTES

### P: ¿Cuántos productos puedo agregar?
**R:** Ilimitados. Agrega todos los que necesites. La página se optimiza automáticamente.

### P: ¿Se ven los cambios inmediatamente?
**R:** Sí. Al hacer clic en "Guardar", la web se actualiza automáticamente. Pueden pasar 5-10 segundos en verse reflejados.

### P: ¿Puedo cambiar precios en tiempo real?
**R:** Sí. Edita el producto y cambia el precio. Se actualiza al instante.

### P: ¿Qué pasa si subo una imagen de mala calidad?
**R:** Se aceptará pero se verá pixelada. Recomendamos comprimir antes: https://imagecompressor.com/

### P: ¿Qué tamaño de imagen es mejor?
**R:** 
- Productos: 800×800px
- Blog: 1200×600px
- Recetas: 1000×800px

### P: ¿Puedo eliminar un producto y recuperarlo?
**R:** Sí, pero avísale al desarrollador. Se guardan respaldos.

### P: ¿Hay limite de posts en el blog?
**R:** No. Puedes escribir todos los que quieras.

### P: ¿Los cambios se guardan automáticamente?
**R:** No. Debes hacer clic en "Guardar" explícitamente. Si olvidas, se pierden los cambios.

### P: ¿Puedo cambiar la contraseña?
**R:** Sí. Ve a Configuración → Cambiar contraseña.

### P: ¿Mi contraseña es segura?
**R:** Sí. Se encripta en la base de datos. Nadie (ni el desarrollador) puede verla.

### P: ¿Qué pasa si escribo mal?
**R:** Puedes editar después. No hay problema. Haz clic en Editar → Cambias el texto → Guardas.

### P: ¿Puedo tener varios administradores?
**R:** Sí. Contacta al desarrollador para agregar más cuentas admin.

### P: ¿Hay respaldo de mis datos?
**R:** Sí. El servidor hace respaldos automáticos diarios. Pero es bueno que tengas copias locales también.

### P: ¿Qué pasa si la web se cae?
**R:** Contacta al desarrollador. No es tu culpa. Él lo arreglará.
